##### **# Shopping Bill Generator 🛒**



###### &#x20;**Description**

The Shopping Bill Generator is a Python-based program that creates a formatted shopping bill. It accepts product names, quantities, and prices from the user and calculates the subtotal, discount, tax, and final amount.



###### &#x20;**Objectives**

\- Practice Python lists and dictionaries.

\- Use loops and functions to organize the program.

\- Calculate discounts, taxes, and total costs.

\- Generate a clear and itemized shopping bill.

###### 

###### &#x20;**Features**

\- Add multiple products to the bill.

\- Calculate the total price of each product.

\- Apply discount percentages.

\- Calculate tax after deducting the discount.

\- Display a formatted bill with monetary values.

\- Handle invalid inputs and empty product lists.



###### &#x20;**Technologies Used**

\- Programming Language: Python

\- Concepts: Lists, Dictionaries, Loops, Functions, Conditional Statements, Exception Handling



###### &#x20;**How to Run**

1\. Install Python on your computer.

2\. Save the program as `shopping\_bill\_generator.py`.

3\. Open a terminal or command prompt.

4\. Run the following command: python shopping\_bill\_generator.py

5\. Enter the product names, quantities, and prices.

6\. Type `done` when you finish adding products.

7\. Enter the discount and tax percentages to generate your bill.



###### &#x20;**Calculation**

\- Subtotal: Sum of all product totals.

\- Discount: Subtotal × Discount Percentage / 100.

\- Tax: Amount after discount × Tax Percentage / 100.

\- Final Amount: Subtotal − Discount + Tax.

Through this project, I learned how to store product details using dictionaries, manage multiple items using lists, create reusable functions, perform calculations, and format output neatly in Python.
